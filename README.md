# Zombie Harvest Loot (7 Days to Die V3.2)

Harvest human zombies with a **knife / butcher tool** for:

- Rotting flesh
- Animal fat
- Cloth
- Extra clothing on tougher / “dressed” zombies
- Job-themed extras (low chance)

XML-only. EAC can stay on if you use no other DLLs.

Built with [Grok Build](https://grok.com).

## Install

1. Close the game.
2. Download `ZombieHarvestLoot-1.0.0.zip` from [Releases](https://github.com/daaag0n00969/7dtd-zombie-harvest-loot/releases).
3. Extract to:

```
%APPDATA%\7DaysToDie\Mods\ZombieHarvestLoot\
```

4. Start the game. Works on an existing save.

## Harvest extras

| Zombie | Extra (chance) |
|---|---|
| All human zombies | Rotting flesh, fat, cloth |
| Nurse / lab | Bandages, painkillers |
| Utility worker / janitor | Hammer, nails, cloth |
| Lumberjack | Iron fireaxe, wood |
| Soldier / cop | 9mm, pistol (rare), extra outfit on soldiers |
| Biker / bowler | Clothing / extra cloth |

Use a blade with butcher harvest (hunting knife, machete, etc.) on the **corpse**.

Loot-bag drop chance on the base zombie template is raised slightly (`0.04` → `0.08`).

## Uninstall

Delete `Mods\ZombieHarvestLoot`.
